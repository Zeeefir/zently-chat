# Zently

Локальный прототип мессенджера по утверждённому дизайну: тёмные панели, розовые сообщения, лаймовая навигация и стеклянная строка ввода. Без сборки; libphonenumber-js проверяет номера и коды стран.

## Запуск

Нужен Node.js 22 или новее. Открой папку в VS Code и выполни:

```sh
npm ci
npm start
```

Открой http://127.0.0.1:3000. Для разработки: `npm run dev`. Проверки: `npm run check` и `npm test`.

## Что работает

- Регистрация/вход по телефону и имени пользователя. **Локальный код отображается на экране, настоящие СМС не отправляются.** Не вводи чужие или конфиденциальные номера.
- Выбор страны автоматически меняет телефонный код. Национальные номера приводятся к международному формату; полный номер с `+` можно вставить целиком. Первоначальный регион определяется приблизительно по часовому поясу/региону браузера и всегда доступен для изменения. Выбор страны запоминается, сам номер — нет.
- Демо-вход без номера. Контакты Алина, Марк, Друзья и Семья — примеры; они не получают сообщения и не отвечают автоматически.
- Отправка и хранение сообщений, поиск чатов, реакции, архив, личное «Избранное», редактирование профиля.
- Через «Новый чат» можно найти пользователя по юзеру с `@` или без него, без учёта регистра, и открыть переписку. Поиск работает среди аккаунтов этого сервера.
- Галочки исходящих сообщений: одна — сохранено/отправлено, одна чёрная — клиент получателя подтвердил доставку, две лаймовые — сообщение отображалось в открытой видимой переписке. Это не распознавание взгляда человека. Статусы сохраняются на сервере; демонстрационные старые диалоги имеют отдельные примерные статусы. В «Избранном» одна галочка означает сохранение личной заметки.
- Изображения и PDF до 1 МБ, просмотр медиа из переписок.
- Обновления между настоящими аккаунтами через SSE. Для проверки создай два аккаунта в отдельных профилях браузера на одном сервере и выбери их через «Новый чат».
- Экран демо-звонка с явной маркировкой. WebRTC и сигналинг для реальных пользователей на одном сервере; камера/микрофон запрашиваются только при настоящем вызове.
- При исходящем вызове звучат гудки, при входящем — оригинальная синтезированная мелодия. Звук останавливается при ответе, отмене, отклонении и таймауте 30 секунд. В настройках можно отключить звук или прослушать мелодию. Если браузер запрещает автозвук до первого действия пользователя, во входящем окне появляется кнопка включения мелодии. При закрытом сайте звонок не поступает: push-уведомления пока не реализованы.
- Адаптивная мобильная раскладка, клавиатурная навигация, native dialog, reduced motion.

Enter отправляет сообщение, Shift+Enter добавляет строку. Меню сообщения появляется при наведении или фокусе. Галочка означает сохранение на сервере, а не прочтение.

## Данные и ограничения

База — `data/db.json` (исключена из Git). Данные сохраняются после перезапуска, сессии и коды хранятся в памяти и сбрасываются при перезапуске. Локальная база не зашифрована. Сервер по умолчанию доступен только на этом компьютере.

Это основа для дальнейшей разработки, не готовый публичный сервис. Для публикации нужны SMS-провайдер, HTTPS, полноценная БД, устойчивые сессии, ограничения нагрузки, резервное копирование и дополнительный аудит. Для звонков между разными сетями нужен STUN/TURN; сейчас WebRTC использует только прямые кандидаты. Сквозное шифрование сообщений не реализовано. Не публикуй сервер разработки наружу.

`ZENTLY_DEV_MODE=0` отключает демо-авторизацию и локальные коды; без SMS-интеграции регистрация будет недоступна. Переменные из `.env.example` задаются через окружение процесса, файл автоматически не читается.

## Дизайн и ресурсы

Шрифт Manrope: лицензия `public/assets/OFL-Manrope.txt`. Фото взяты из предоставленных пользователем дизайн-референсов. Логотип — редактируемый SVG: розовый чат, чёрная линия, лаймовая точка.

Структура: `public/` — интерфейс, `server/` — API/хранилище, `tests/` — проверки, `DESIGN.md` — визуальная система, `UX-CONTRACT.md` — правила поведения.
