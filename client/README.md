# Тестовый клиент newsChat

Запуск API из корня: docker compose up -d
Запуск клиента: cd client, затем npm run dev
Адрес: http://localhost:5173

Vite перенаправляет /api на http://localhost:9090. Секреты Pusher остаются на сервере.
Публичные key и cluster клиент получает через /api/realtime/config после входа.

Проверка:
1. Откройте обычное и приватное окно браузера (две обычные вкладки используют одну сессию).
2. Создайте разные аккаунты. Регистрация автоматически выполняет вход.
3. Найдите собеседника по имени или точной почте и откройте диалог с обеих сторон.
4. Дождитесь «Pusher: подписка активна».
5. Отправьте сообщение. В другом окне оно должно появиться без обновления, счётчик событий увеличится.
6. Если Pusher недоступен, кнопка «История» загружает сохранённые сообщения вручную.

Автоопрос сообщений отключён, чтобы не маскировать проблемы Pusher.
История обновляется при возвращении фокуса, восстановлении подписки и вручную.
## Проверка видеозвонка

1. Откройте сайт в двух браузерах и войдите в разные аккаунты.
2. Выберите переписку и нажмите «Позвонить».
3. Разрешите камеру и микрофон; во втором браузере нажмите «Принять» и тоже разрешите доступ.
4. Проверьте видео, звук, выключение микрофона/камеры и завершение с обеих сторон.
5. Для теста на одном компьютере используйте наушники, чтобы избежать эха.
6. Без камеры/микрофона браузер покажет ошибку; разрешения меняются в настройках сайта.

Приглашения приходят через личный Pusher-канал, даже если открыта другая переписка.
Каждые 4 секунды клиент сверяет состояние звонка/сигналы с API для восстановления после пропущенных событий.
Для WebRTC используется публичный STUN из примера webrtc.org. TURN не настроен:
между разными сетями соединение не гарантируется. На публичном домене нужен HTTPS.
После перезагрузки страницы во время звонка завершите старый звонок и начните новый.
Завершение при закрытии вкладки отправляется с keepalive, но при обрыве сети не гарантируется.

Проверки: npm test (Node 24+), npm run build, npm run lint.
Тесты контроллера используют подмену камеры и сети; реальное видео проверяется двумя браузерами.

Файлы:
- src/api.ts — Axios, типы данных и ошибки.
- src/App.tsx — вход, список диалогов и переписка.
- src/main.tsx — QueryClientProvider и точка входа.
- src/index.css — Tailwind.
- vite.config.ts — proxy и алиас @.

Запуск всего проекта через Docker: из корня docker compose up -d --build --wait. Сайт: http://localhost:3000. Подробности в корневом README.md.

- src/calls.ts — состояние звонка, Pusher и WebRTC.
- src/CallPanel.tsx — входящий вызов, видео и кнопки управления.
